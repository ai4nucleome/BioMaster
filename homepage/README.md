# BioMaster Homepage

This directory contains a static multi-page project homepage for BioMaster.

## Pages

- `index.html`: project overview and key metrics
- `paper.html`: manuscript summary and citation
- `system.html`: multi-agent architecture and dual RAG design
- `benchmark.html`: supported workflows, case studies, benchmark results, and figures
- `team.html`: authors and affiliations
- `docs.html`: installation, documentation, and repository links

## Local Preview

Open `index.html` directly in a browser. No build step is required.

## Deployment

The site is plain HTML, CSS, and JavaScript. It can be deployed by copying the
contents of this directory into the GitHub Pages publishing directory, such as
`docs/`, or by publishing this directory with a GitHub Pages Action.
