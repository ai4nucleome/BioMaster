# Bioskills Single Cell Splicing

## Overview

This workflow guides single-cell splicing analysis from chemistry assessment through differential splicing calls. It begins by gating on whether the sequencing chemistry (plate-based full-length vs 10X 3' droplet) can support transcriptome-wide splicing inference, then routes to the appropriate tool (MARVEL, BRIE2, SpliZ, Psix, Sierra, or pseudobulk leafcutter/rMATS). Inputs are STAR-aligned BAMs or SJ.out.tab files, a GTF/GFF3 annotation, per-event feature tables, and per-cell metadata (typically a Seurat or h5ad object). Outputs include per-cell PSI matrices with modality classifications, cell-state-association statistics (LRT delta-ELBO, Wilcoxon, graph-smoothness scores), and differential splicing calls between cell types or along trajectories. Use this workflow when you have plate-based (Smart-seq2/3, FLASH-seq, VASA-seq, STORM-seq) or long-read (MAS-Iso-seq, scISOr-Seq2, ONT) single-cell data and want per-cell isoform-level inference. For 10X 3' data, the chemistry does not support transcriptome-wide cassette-exon splicing; use the Sierra APA pivot instead. The fundamental decision is chemistry, not tool: most droplet 3' scRNA-seq cannot support splicing inference because reverse transcription primes from the poly(A) tail and most reads land in the 3' UTR, far from CDS-region splicing events.

## Chemistry Assessment & Tool Selection

Gate on whether the sequencing chemistry supports transcriptome-wide splicing inference before any analysis. 10X 3' (v3, GEM-X, v4, Flex) cannot support it because reverse transcription primes from the poly(A) tail, leaving over 70% of reads in the 3' UTR with effective junction yield below 0.1 per cell per alternative splicing event; 10X 5' GEX is only marginally better (shifts capture to 5' UTR / TSS-proximal regions). Plate-based full-length methods (Smart-seq2/3, FLASH-seq, VASA-seq, STORM-seq) and single-cell long-read (MAS-Iso-seq, scISOr-Seq2, ONT direct cDNA/RNA) do support per-cell isoform structure across the gene body. Select the tool by goal: MARVEL for unified Smart-seq or 10X droplet workflows with modality classification; BRIE2 for Bayesian PSI with principled uncertainty in low-coverage cells; SpliZ for annotation-free cell-state-associated splicing discovery; Psix for regulated AS along developmental trajectories; Sierra for APA in 10X 3' (not splicing); pseudobulk leafcutter or rMATS for between-cell-type differential splicing with bulk-level power; FLAMES for long-read full-isoform analysis. Verify installed package versions match the tested references before running any code.

## Junction Quantification & Object Construction

Build the wide splice-junction count matrix from STAR SJ.out.tab files (one per cell), keyed by coord.intron (formatted chr:start:end) with per-cell sample IDs as columns and integer junction counts as values. Assemble per-event feature tables as a named list keyed by event class (SE, A5SS, A3SS, MXE, RI). Prepare per-cell metadata with a sample.id column mapping to the junction matrix column names. Construct the MARVEL object with named slots: SpliceJunction, SplicePheno, SpliceFeature, GeneFeature, Exp, and GTF. For BRIE2, prepare a GFF3 of splicing events and a sample list TSV, then run brie-count to produce cell-barcoded junction counts in an h5ad file. For 10X droplet data, MARVEL v2+ provides CreateMarvelObject.10x() and AnnotateSJ.10x() constructors; verify the exact API via the installed package help. The SpliceJunction matrix must be wide-format — long-format data frames or a missing coord.intron column cause runtime errors; use data.table dcast for the long-to-wide reshape.

## Per-Cell PSI Estimation & Modality Classification

Quantify per-cell PSI for each event class and classify the PSI distribution shape. MARVEL's ComputePSI applies a coverage threshold (default 10 reads per event per cell) and AssignModality classifies events into included (PSI peaked at 1), excluded (peaked at 0), bimodal (mixture at 0 and 1, reflecting mixed cell states or stochastic monoallelic-like bursting), middle (peaked around 0.5, often technical from well-contamination, doublets, or low-coverage shrinkage to prior — confirm with full-length data), or multimodal (complex regulation). BRIE2 fits a Bayesian variational model with a sequence-derived regulatory-feature prior (exon length, GC content, splice site strength, motif counts) to regularize PSI estimates in low-coverage cells; the principled output is the ELBO_gain cell-state-association statistic, not the noisy per-cell point estimate. With sparse counts, binomial PSI is overdispersed; beta-binomial models (BRIE2) or Dirichlet-multinomial cluster-level models (leafcutter2) handle this. For very sparse droplet data, even beta-binomial fits poorly per cell — collapse to pseudobulk. Do not impute PSI matrices: naive imputation (MAGIC, scImpute, ALRA) averages over neighboring cells and obliterates the heterogeneity you want to study.

## Differential Splicing & Cell-State Association Testing

Test for splicing differences between cell types or coherent variation along trajectories. MARVEL's CompareValues runs Wilcoxon (or other) tests between cell groups with a minimum cell count (n.cells, default 25) and PSI delta threshold (psi.delta, default 0.1). BRIE2 likelihood-ratio testing on covariate effects is configured via --LRTindex All and --testBase null; threshold delta-ELBO at approximately 3 (analogous to a log-Bayes-factor). SpliZ computes per-gene splicing Z-scores across cells and tests cell-state association via permutation, robust to dropout because it pools junction information across the gene; it is particularly useful for discovering splicing diversity in heterogeneous tumor samples without an event database. Psix tests whether observed PSI is smooth on the cell-cell kNN graph from expression-space embedding — the principled alternative to imputing PSI; it requires a precomputed neighbors graph (run sc.pp.neighbors first). Pseudobulk aggregation sums junction counts across cells of the same cluster, then runs leafcutter or rMATS for bulk-level statistical power between well-defined cell types. Use per-cell methods for within-population heterogeneity (graded splicing along pseudotime, bimodal cell-state mixtures); use pseudobulk for between-cell-type comparisons where effect is averaged out per-cell.

## APA Analysis with Sierra (10X 3' Pivot)

When the chemistry does not support cassette-exon splicing (10X 3' data), pivot to alternative polyadenylation analysis with Sierra — frequently confounded with AS but biologically distinct. Sierra peak-calls read pile-ups at 3' ends within annotated 3' UTRs, then runs DEXSeq-style differential transcript usage (DTU) on 3' UTR isoforms between cell groups. Distinct UTRs change miRNA targeting, RBP binding, and mRNA stability — biologically meaningful but not splicing. If the GTF is missing 3' UTR annotations, few peaks will be detected; use comprehensive GENCODE annotation or run de-novo peak calling first. Note that 10X 5' GEX does not solve the splicing problem either — it shifts capture from 3' UTR to 5' UTR / TSS-proximal regions with only marginal improvement. For V(D)J recovery, the dedicated 10X Chromium Single Cell Immune Profiling kit (with TCR/BCR-specific enrichment) is required, not 5' GEX alone.

## Quality Control, Failure Modes & Reconciliation

Apply quality thresholds and diagnose failures across the workflow. Require at least 50 cells per event with reads for per-cell PSI (200 cells per cluster for pseudobulk), at least 5 junction reads per event per cell (1 or fewer is unreliable), and PSI variance below 0.1 within a cluster but above 0.2 between clusters for a cell-type call. Doublet filtering (DoubletFinder, Scrublet) is required before splicing analysis because doublets create artificial PSI mid-modality. For snRNA-seq, nuclear RNA is enriched for incompletely spliced transcripts, so intron retention baseline is high — interpret IR cautiously. When single-cell tools disagree, reconcile by pattern: MARVEL significant but BRIE2 not suggests per-cell PSI noise (trust MARVEL for cell-type comparisons, BRIE2 for within-cluster); BRIE2 significant but MARVEL not suggests a smoother cell-state effect (test along trajectory with Psix); SpliZ significant but MARVEL not suggests novel events caught annotation-free; Sierra significant but MARVEL not means APA vs splicing — different biology; pseudobulk significant but per-cell not indicates a power issue best reported at cluster level.
