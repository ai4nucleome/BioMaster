# Bioskills Combinatorial Screens

## Overview

This workflow analyzes combinatorial CRISPR screens to identify synthetic-lethal and synthetic-rescue genetic interactions (GIs) between gene pairs. It supports two architectures: paired-Cas9 (Big Papi) analyzed with MAGeCK MLE interaction terms, and Cas12a multiplex (in4mer / Inzolia) analyzed with custom per-pair GI scoring. The biological motivation is paralog buffering — roughly half of constitutively-expressed essential genes are missed by single-gene Cas9 KO screens because paralogs provide redundant function; only combined loss of both paralogs reveals the essential phenotype (Dede 2020; Thompson 2021).

Inputs: raw sgRNA or cassette count tables from a pooled combinatorial screen, a design matrix (for MAGeCK MLE) or a cassette-to-gene-pair annotation table (for in4mer), and singleton single-gene KO controls. Outputs: per-pair genetic-interaction scores (GI z-scores) classifying each pair as synthetic-lethal (GI z < -2), synthetic-rescue (GI z > 2), or no-interaction (additive), plus a validated hit list for drug-target nomination.

Use this skill when screening paralog pairs or pathway pairs for buffering / synthetic-lethal relationships, especially when single-gene Cas9 screens miss essential paralogs. The workflow proceeds: (1) select architecture and design the library with singleton controls, (2) QC library representation and singleton coverage, (3) quantify per-pair effects via MAGeCK MLE (Cas9 path) or cassette aggregation (Cas12a path), (4) score genetic interactions against the additive null, (5) diagnose failure modes and validate high-stakes hits orthogonally. Reference versions: MAGeCK 0.5.9+, Inzolia library annotation (Bayle 2024), pandas 2.2+, numpy 1.26+, scipy 1.12+.

## Architecture Selection & Library Design

Choose between paired-Cas9 (Big Papi) and Cas12a multiplex (in4mer / Inzolia) architectures based on the screen goal. For genome-scale paralog buffering, prefer Cas12a multiplex with the Inzolia library (~4,000 paralog pairs, 4 guides per cassette, ~30% smaller library than paired-Cas9). For testing a specific pathway pair, use Big Papi paired-Cas9 dual-sgRNA cassettes. For 3- or 4-way knockout, use in4mer 4-guide arrays. Critically, the library MUST include singleton controls (each gene targeted alone with placeholder guides) because GI scoring requires single-gene LFC baselines; without singletons, expected-additive cannot be computed. Pilot Cas12a editing efficiency at target loci before committing to a full screen, since Cas12a is less efficient than Cas9 at some loci. Use enCas12a (enhanced variant) for higher efficiency. Avoid fused Big Papi cassettes by using validated paired-sgRNA cloning protocols and verifying clones by amplicon sequencing.

## Library QC & Singleton Verification

Verify library representation and singleton controls before scoring. Check cassette skew (Gini coefficient), per-cassette coverage (at least 500 cells at infection), and confirm that all singleton controls are present and well-represented. Low-coverage cassettes yield noisy LFCs and GI z-scores that vary 2-3x across cassettes targeting the same pair; flag or drop these. Confirm version compatibility for MAGeCK and Python dependencies (pandas, numpy, scipy, matplotlib). If code throws ImportError, AttributeError, or TypeError, introspect the installed package and adapt to the actual API rather than retrying. Standard library QC (Gini, skew) applies to combinatorial libraries just as to single-guide libraries.

## MAGeCK MLE with Interaction Terms (Cas9 / Big Papi Path)

For paired-Cas9 (Big Papi) screens, run MAGeCK MLE with a design matrix that encodes single-A, single-B, and double-AB conditions plus an explicit interaction indicator column set to 1 only for double-KO samples. The resulting beta for the interaction column captures the additional joint effect beyond the sum of the single-gene betas. A significantly negative interaction beta indicates synthetic lethality; positive indicates synthetic rescue. Note that MAGeCK MLE does not natively perform a formal interaction-significance test against the additive null; for formal GI hypothesis testing, use the explicit GI scoring approach in the next step. Interpret the output columns: geneA|beta and geneB|beta are single-gene effects, interaction|beta is the additional joint effect, and interaction|fdr is its significance versus zero.

## Cas12a 4-Guide Array Aggregation (in4mer / Inzolia Path)

For in4mer / Inzolia Cas12a screens, aggregate cassette-level counts to per-pair log-fold changes. Each paralog pair is targeted by 4 cassettes with different guide combinations; aggregate by gene pair (gene_A, gene_B). The Inzolia library covers ~4,000 paralog pairs with ~18,000 total 4-guide cassettes, and includes singleton controls where each gene is targeted alone with placeholder guides. These singletons provide the single-gene LFC baselines needed for GI scoring. For low-coverage pairs, aggregate fewer cassettes but with more sequencing depth, or drop low-coverage pairs from the analysis to reduce noise.

## Genetic Interaction Scoring

Compute genetic interaction scores from per-pair and per-singleton LFCs. GI = observed_double_LFC - (single_A_LFC + single_B_LFC), measuring deviation from the additive expectation. Z-score the GI across all pairs. Classify each pair: GI z < -2 = synthetic lethal (double-KO more lethal than additive; candidate drug-target combinations), GI z > 2 = synthetic rescue (double-KO less lethal than additive; compensatory pathway or paradoxical hit), -1 to 1 = no interaction (additive). Use log-space (LFC) GI scoring rather than linear-space to avoid saturation artifacts: when two cell-cycle genes each cause 50% growth arrest, the combined 75% arrest saturates proliferation in linear space, generating false synthetic-rescue calls. Log-space scoring is less sensitive to this saturation. Do NOT use single-gene LFCs from a different cell line (e.g., DepMap HCT116 baselines for a K562 screen) as the additive baseline; single-gene effects are cell-line-specific and yield noisy false-positive GIs. Always include singleton controls in the same screen.

## Failure Diagnosis & Cross-Modality Validation

Diagnose common failure modes and validate high-stakes synthetic-lethal hits before drug-target nomination. Failure modes include: fused Big Papi cassettes (two sgRNAs read as one fused sequence, appearing as a single perturbation), low Cas12a editing efficiency at specific loci (<50%, causing missing expected effects), missing singletons (cannot compute expected-additive), cell-line-mismatched single-gene baselines (using DepMap data from a different line yields noisy false positives), and proliferation saturation in linear-space scoring (false synthetic-rescue calls for pairs of essential cell-cycle genes). For high-stakes hits, validate orthogonally: re-test with the opposite nuclease chemistry (Cas9 if Cas12a, or vice versa), perform arrayed single-KO validation in the same cell line, confirm with CRISPRi (dCas9-KRAB, no DNA damage), and test pharmacological inhibition of the paralog to confirm drug accessibility.
