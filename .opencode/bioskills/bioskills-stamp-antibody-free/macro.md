# Bioskills Stamp Antibody Free

## Overview

This skill profiles RNA-binding protein (RBP) targets without UV crosslinking or immunoprecipitation by expressing a deaminase-RBP fusion (APOBEC1 for STAMP, ADAR for TRIBE, APOBEC1-YTH for DART-seq) that edits RNA nucleotides adjacent to where the RBP binds. The editing signature (C-to-U for STAMP/DART, read as C-to-T; A-to-I for TRIBE, read as A-to-G) is recovered computationally from standard RNA-seq or scRNA-seq libraries by comparing the fusion sample against a matched deaminase-only control, which captures the intrinsic baseline editing of the deaminase alone.

Inputs: paired-end RNA-seq FASTQs (or 10x Genomics / Smart-seq2 single-cell libraries) from the fusion sample AND a matched deaminase-only control, plus a reference genome and annotation. Outputs: a filtered set of high-confidence RBP-specific editing sites (BED/TSV) for bulk profiling, and for single-cell data a per-cell or per-cluster editing-rate matrix that can be integrated with standard scRNA-seq clustering and cell-type annotation.

Use this workflow when: an antibody for the RBP is unavailable; UV crosslinking is not possible (tissue / in vivo); single-cell RBP profiling is required; or m6A-reader targets are sought (DART-seq). Trade-offs: editing is offset 0-50 nt from the actual binding site so resolution is approximate (use CLIP/eCLIP for precise localization); off-target deaminase activity must be subtracted via the control; and high fusion expression saturates editing and destroys specificity. STAMP (Brannan 2021) is the canonical method; scSTAMP (Brannan 2024) extends it to single-cell; TRIBE (McMahon 2016) and HyperTRIBE (Xu 2018) are ADAR-based variants; DART-seq (Meyer 2019) targets m6A readers.

## Method Selection & Experimental Design

Choose the deaminase fusion strategy based on the biological question and system. STAMP (APOBEC1-RBP) produces C-to-U edits, is well-validated in mammalian cells, extends natively to single-cell (scSTAMP), and has cleaner background because C-to-U is rare in mRNA. TRIBE (ADAR-RBP) produces A-to-I edits, is best validated in Drosophila, but in mammals competes with baseline ADAR activity at ALU repeats. DART-seq (APOBEC1-YTH) profiles m6A-reader targets rather than direct RBP binding and edits 0-50 nt from the m6A site. A matched deaminase-only control (APOBEC1 alone or ADAR catalytic domain alone) must always be run in parallel, because deaminases have intrinsic baseline editing (APOBEC1 ~3-5% C-to-U; ADAR ~5-10% A-to-I at ALUs) that must be subtracted. Titrate fusion expression with an inducible promoter to low-to-moderate levels; high expression (>>10x endogenous) saturates editing so every accessible site is edited regardless of RBP binding. Decide bulk versus single-cell readout based on coverage needs: 10x scSTAMP is sparse per cell, Smart-seq2 (~1M reads/cell) gives deeper per-cell coverage.

## Alignment & BAM Generation

Align RNA-seq reads to the reference genome to produce position-sorted, indexed BAMs for both the fusion sample and the deaminase-only control. For bulk RNA-seq use STAR in two-pass mode to improve splice-aware alignment around edit sites. For 10x Genomics single-cell libraries use cellranger count, which produces a per-cell-barcode position-sorted BAM plus the filtered barcode list. For Smart-seq2 plates align per-plate with STAR. Preserve read-strand information throughout, because downstream edit calling must distinguish a true C-to-U on the transcribed strand from its reverse-complement (G-to-A) artifact on the opposite strand. Index all BAMs with samtools index.

## Editing-Site Detection

Call candidate editing sites from the aligned BAMs using an editing-aware tool. For STAMP/DART-seq (C-to-U) use Bullseye (Meyer lab, a multi-script Perl pipeline) or SAILOR (Yeo lab, a Snakemake workflow). For TRIBE/HyperTRIBE (A-to-I) use REDItools2 or JACUSA2. JACUSA2 is a general-purpose multi-sample caller that ingests fusion and control BAMs together in call-2 mode and reports per-site edit type, edit rate, coverage, and strand. Run the fusion sample and the deaminase-only control through the same pipeline so that per-site metrics are directly comparable for the subsequent subtraction step. Do not use a generic variant caller, because it lacks strand awareness and will conflate C-to-U signal with its reverse complement.

## Control Subtraction & Specificity Filtering

Subtract the deaminase-only control to retain only RBP-specific editing sites. Apply quantitative thresholds: edit rate >= 0.1, per-site coverage >= 10 reads, and a fusion-to-control edit ratio > 3 as the specificity cutoff. Filter strand-specifically so that only C-to-U on the transcribed strand (STAMP/DART) or A-to-I (TRIBE) is retained, removing reverse-complement artifacts and anti-sense transcription noise. For TRIBE in mammals, additionally remove edits overlapping ALU repeats unless the RBP is known to bind repeats, because baseline ADAR activity at ALU dsRNA structures dominates the apparent target list. For STAMP, filter out genomic C-to-T SNVs that are actually APOBEC1 ssDNA off-target activity read through transcription. The output is a high-confidence, RBP-specific editing-site list.

## Single-Cell scSTAMP Analysis

For single-cell libraries, quantify per-cell editing rates and integrate the result with standard scRNA-seq clustering. Run the scSTAMP analysis script on the cellranger BAM and filtered barcode list, supplying the APOBEC1-only sample as the control, to produce a per-cell edit-rate matrix. Because per-cell coverage is sparse (single cells carry ~5000-50000 mRNA molecules and most positions have 0-3 reads per cell), aggregate cells into pseudobulk by Leiden cluster or annotated cell type to recover a robust editing signal; ultra-deep Smart-seq2 (~1M reads/cell) is an alternative when higher per-cell coverage is required. The per-cell or per-cluster binding profile can then be overlaid on the scRNA-seq cell-type annotation to recover cell-type-specific RBP targets. Pseudobulk scSTAMP results should concord with bulk STAMP for low-coverage targets.

## Validation & Failure-Mode Handling

Validate the editing-site list and diagnose common failure modes. Cross-reference STAMP/TRIBE targets with orthogonal eCLIP data where available: STAMP and eCLIP are complementary, with STAMP more sensitive for low-abundance or poorly-crosslinking targets and eCLIP giving precise binding-site resolution. Diagnose APOBEC1 saturation (edit count per gene far above expected, control nearly as edited as fusion) by titrating fusion expression down with an inducible promoter. Diagnose ALU-dominated TRIBE signal by subtracting the ADAR-only control and filtering ALU overlaps. Diagnose APOBEC1 ssDNA off-target by requiring strand-specific RNA edits and filtering genomic SNVs. Diagnose sparse scSTAMP per-cell signal by pseudobulking by cluster or switching to Smart-seq2. Treat STAMP/TRIBE as hypothesis-generating, antibody-free profiling; use CLIP/eCLIP for high-resolution validation, and report STAMP+eCLIP concordance for top targets as the strongest figure.
